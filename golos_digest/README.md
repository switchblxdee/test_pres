# golos_digest — генератор дайджеста «Голос IT»

xlsx (листы «разметка» + «свод») → .pptx в дизайне примера.

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml                     # пути к сертификатам, модель, контур
python -m golos_digest выгрузка.xlsx -o digest.pptx -c config.yaml
python -m golos_digest выгрузка.xlsx --backend heuristic   # без LLM, для отладки вёрстки
python run_digest.py выгрузка.xlsx                         # со своим объектом GigaChat(...)
python tools/make_demo_xlsx.py demo.xlsx               # синтетика в боевом формате
python -m pytest -q tests                              # 44 теста
```

Из кода:

```python
from langchain_gigachat.chat_models import GigaChat
from golos_digest import DigestAgent

agent = DigestAgent("config.yaml", llm=GigaChat(...))   # llm не передан -> создаётся из config.llm
result = agent.run("выгрузка.xlsx", "digest.pptx")       # DigestResult: path, n_slides, llm_calls, ...
agent.graph                                             # скомпилированный LangGraph
print(agent.draw())                                     # mermaid-схема графа
```

Авторизация GigaChat: mTLS (`llm.cert_file` + `llm.key_file`, ключ не нужен) или
ключ в переменной `GIGACHAT_CREDENTIALS`. Пароль от зашифрованного ключа — `GIGACHAT_KEY_PASSWORD`.

## Как устроено

| Модуль | Что делает |
|---|---|
| `data.py` | Читает листы, сопоставляет колонки по синонимам, считает динамику, новые/возобновлённые темы, KPI |
| `agent.py` | `DigestAgent`: граф LangGraph `load → (Send × темы) select_quotes → assemble → render`, узлы — методы класса |
| `quotes.py` | Эвристический префильтр → LCEL-цепочка ранжирования (structured output + текстовый фолбэк + retry) → кэш |
| `measure.py` | Перенос строк по реальным метрикам шрифта (PIL) |
| `render.py` | Пагинация + клонирование компонентов эталонного слайда шаблона |
| `ooxml.py` | XML-хелперы: уникальные id, перенос связей картинок, перезапись текста с сохранением стилей |

**Дизайн не рисуется кодом.** Фон, шрифты, иконки (включая векторные), карточки и бейджи
клонируются из `template/template.pptx` — это присланный пример. Код меняет только текст
и координаты, поэтому стиль совпадает с примером точь-в-точь. Если дизайнер обновит шаблон,
достаточно подменить файл; при изменении id фигур — поправить словарь `T` в `render.py`.

**Граф LangGraph.** Отбор цитат — fan-out через `Send`: каждая тема отдельная параллельная ветка,
результаты сливаются редьюсером; параллелизм ограничен `llm.max_workers` (`max_concurrency`).
Модель — `langchain_gigachat.GigaChat` (или `ChatOpenAI` для openai-совместимого API); свою
модель передаётся в `DigestAgent(cfg, llm=...)`. Ответы reasoning-моделей с блоком
`<think>…</think>` разбираются корректно; если контур не поддерживает function calling —
`llm.structured_output: false`, тогда на тему уходит ровно один запрос.

**LLM выбирает только номер сообщения**, текст цитаты берётся дословно из разметки:
модель не может выдумать или исказить цитату. Ответ берётся через `with_structured_output(Ranking)`;
если модель ответила текстом — парсер JSON из текста; после ретраев — эвристика (такой результат
не кэшируется, чтобы следующий прогон снова сходил в LLM).

## Правила данных

- Новая тема: сигналов прошлой недели 0 или пусто → закладка вместо бейджа.
- Возобновилась: колонка «Возобновилась» = да, или в статусе есть «возобнов» → иконка ↻.
- Динамика %: считается из текущих/прошлых сигналов; колонка «Динамика %» — только фолбэк.
  Рост — красный ▲, падение — зелёный ▼, 0% — без бейджа.
- Иконка статуса: колонка «Иконка статуса» (если появится) или regex из `status_icon_rules`.
- Порядок: продукты по сумме сигналов, темы внутри по убыванию; сквозная нумерация 01, 02…
- Строка не влезает на слайд → цитата ужимается до 2 строк с «…», иначе перенос на новый
  слайд с повтором шапки продукта.
- План вёрстки перебирает общий лимит строк цитаты (5 → 3) и берёт вариант с наименьшим
  числом слайдов: на случайных данных это −8% слайдов и меньше «висячих» слайдов.
- Лимиты: название темы ≤ 3 строк, статус ≤ 6, продукт — одна строка шапки; дальше «…».
- Пустой лист «разметка» не ошибка: дайджест строится без цитат. Шапка таблицы может
  быть не в первой строке листа (над ней — заголовок отчёта).

## Устойчивость к просмотрщикам

Текст, который должен стоять рядом (название + цитаты; статус + карточка), живёт в одной
фигуре — переносы считает сам редактор. Однострочные подписи получают запас ширины и
`wrap=square` (а не `none`, который редакторы трактуют по-разному), поэтому деку не
«разносит» в превью и редакторах без шрифта SB Sans.

## Файл

Неиспользуемые лейауты шаблона (с фонами ~3 МБ) и миниатюра примера удаляются, метаданные
перезаписываются (`author` в конфиге) — итоговый файл ~40–60 КБ.

## Шрифты

Для точных переносов положи файлы SB Sans Display (Regular/SemiBold/Light) в папку
и укажи `fonts.fonts_dir`. Без них переносы считаются по Inter/DejaVu с запасом 4%.
